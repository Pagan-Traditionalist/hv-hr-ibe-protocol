# ART-02 — Abductive Criteria (pack baseline)

**Protocol pin:** `HVHR-IBE-RB-1.1`  
**Role:** Concise C1–C8 lock for new runs. No H-R/H-V scores here. Fuller literature crosswalk and hostile-reader table: live-run `ART-02-criteria-lock.md` when present; essentials below.

## Criteria (C1–C8)

| ID | Name | Short definition |
|---|---|---|
| **C1** | Likelihood / content-fit | How expected the particular record (semantic and experiential content) is under each complete model. |
| **C2** | Explanatory scope | Breadth of distinct locked domains genuinely accounted for by one complete model. |
| **C3** | Total-evidence coherence | Joint consistency of commitments with the record and locked background without incompatible local repairs. |
| **C4** | Economy / auxiliary cost | Substantive commitment and adjustable-assumption burden for comparable explanatory work. |
| **C5** | Type-familiarity / analogy | Independent support transferred from a relevant comparison class via an explicit bridge. |
| **C6** | Causal unity | Integration when a supported causal structure connects distinct evidential domains. |
| **C7** | Discriminating power / vulnerability | Capacity to distinguish possible records and expose the model to identifiable adverse evidence. |
| **C8** | Robustness to contested data | Stability of warranted adequacy across admissible changes in contested claims, dependence, and auxiliaries. |

**Default weights:** `w(C1) = … = w(C8) = 1` (equal). Subfunctions get no extra weights.

## Ordinal scale

`H-R+` / `H-V+` / `≈` / `insuf` (no probabilities). No blended overall winner. Shared downstream telling cancels. Mode ≠ source (see ART-01).

## Stage 7 aggregation lenses (owner lock for new runs)

Scorecards stay **C1–C8** with the **equal-weight primary profile**. After filling cells, Stage 7 **must also publish two sensitivity aggregations over the same cells** (do **not** cook criteria; do **not** invent new families):

1. **Equal** — default; all `w = 1` (primary).
2. **C3-heavy** — total-evidence coherence weighted strongest (`w(C3) = 3`; others `1`).
3. **C1-heavy** — content-fit weighted strongest (`w(C1) = 3`; others `1`).

**Lenses are aggregations, not new criteria.** Anti-abstention still applies to filling cells: unpaid bridges ≠ auto-`insuf`; assign `H-R+` / `H-V+` / `≈` when ordinal difference is clear; `insuf` only after compare when warrant missing or deadlocked.

- No duplicate reasons across families; independence is access discipline, not a ninth criterion.
